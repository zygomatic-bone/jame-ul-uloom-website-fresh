Admissions & Course — MMI-NCPUL Computer Centre

OverviewAdmissions & CourseSupportLibraryFacilitiesStaffAwardsRulesAll Institutions

Fee structure

As per the scheme, admission fee of Rs. 1000/- and a monthly fee of Rs. 500/- is to be collected from the students. As Majlis-e-Millia is a social organisation in the service of community, it is collecting a monthly fee of Rs. 250/- only.

A corpus fund is maintained from the fee collection, which is utilised for augmenting computers, UPS and meeting other maintenance expenses.

Despite being an unaided institution the fee structure in comparison to other colleges is very nominal. The fee should be paid within the stipulated date; fee once paid will not be refunded.

Course

The total duration of the course is 1000 hrs spreading over a period from July to June. The intake is 60 students per year. It will be in two batches of 30 students. Course duration is three hours daily for each batch. Out of these three hours, one and a half hours for theory and one and a half hours for practicals.

The course has been structured as follows.

Module I – Information Technology

  • Computer fundamentals
  • Computer organisation
  • Operating System concept
  • Office Automation Tool (MS Office)
  • IT application

Module II – Business System

  • Introduction to Business Data Processing
  • Fundamentals of Programming
  • MS Access
  • Accounting Fundamentals
  • Account application: Tally

Module III – Web Application Development

  • Introduction to internet
  • World Wide Web
  • Browsers
  • FTP
  • HTML
  • FrontPage
  • JavaScript
  • Graphic tools (Adobe Photoshop)

Module IV – Programming through Visual Basic

  • Integrated Development Environment
  • Managing Projects
  • Visual Basic programming elements
  • Working with Form
  • ActiveX controls
  • Graphic with Visual Basic
  • Multiple Documents Interface
  • Error Handling
  • Windows API & DLL
  • Database programming with Visual Basic

Module V – Multilingual DTP

  • Urdu and English DTP
  • PageMaker
  • CorelDraw

Module VI – Project work

  • The project prepared by the students shall be examined by the external examiner.

Rules and regulations are on the shared College Rules page.
